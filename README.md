## 👨‍💻 Sobre mim

Sou **Fernando Santos**, tenho 24 anos e atuo como **Analista de Sistemas / Desenvolvedor Pleno**, com mais de **5 anos de experiência em desenvolvimento de software**.

Atualmente, sou **Analista de Desenvolvimento de Software II na TOTVS**, atuando na **Fábrica de Software**, com foco no ecossistema **TOTVS RM**, principalmente nas áreas de **Gestão Educacional e Gestão Financeira (BackOffice)**.

Minha atuação envolve o desenvolvimento de **customizações, integrações, automações de processos e evolução de funcionalidades do RM**, buscando adaptar o sistema às necessidades específicas dos clientes e simplificar o trabalho dos usuários.

Tenho experiência com soluções para clientes como **SESI, SENAI e SESC**, incluindo **exportação de dados para sistemas de terceiros, integrações entre sistemas e automação de processos**.
