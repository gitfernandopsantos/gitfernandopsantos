Sou Fernando, tenho 24 anos e atuo como **Analista de Sistemas / Desenvolvedor Pleno**, com mais de **5 anos de experiência em desenvolvimento de software**, trabalhando na construção, evolução e manutenção de soluções para diferentes necessidades de negócio.

Atualmente, sou **Analista de Desenvolvimento de Software II na TOTVS**, atuando na **Fábrica de Software**, com foco no ecossistema **TOTVS RM**, principalmente nas áreas de **Gestão Educacional e Gestão Financeira (BackOffice)**.

Minha atuação envolve o desenvolvimento de **customizações, integrações, automações de processos e evolução de funcionalidades do RM**, buscando adaptar o sistema às necessidades específicas dos clientes e simplificar processos para os usuários.

Tenho experiência no desenvolvimento de soluções para clientes como **SESI, SENAI e SESC**, incluindo **exportação e integração de dados com sistemas de terceiros**, automação de processos e desenvolvimento de funcionalidades específicas para as regras de negócio de cada cliente.
